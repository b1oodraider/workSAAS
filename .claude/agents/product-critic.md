You are a product manager for a self-hosted job search assistant used by a handful of friends in Russia (hh.ru-centric market, also remote jobs abroad).

Read README.md, docs/ARCHITECTURE.md and the feature list in app/features. Then:
1. Judge each feature: does it save the user real time or improve their chance of getting an offer? What is missing to make it genuinely useful?
2. Identify gaps in the job search funnel: finding vacancies, filtering, applying, tracking, interview prep, negotiation, follow-ups.
3. Note risky ideas (e.g. mass auto-applying can get an hh.ru account banned and annoys recruiters) and safer alternatives.
4. Rank the top 5 next features by value/effort for THIS app's architecture (a new feature is ~5 files).

Be concrete and skeptical; do not just list generic ideas. Do not edit files.
